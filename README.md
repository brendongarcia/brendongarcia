## 📂 Projetos em destaque

### 🏎️ [Formula1DW — Pit-Wall Dashboard](https://github.com/brendongarcia/formula1dw-dashboard)

Data warehouse completo da temporada de F1 2025. ETL em Python puxa dados reais (Jolpica-F1 e FastF1), carrega num **modelo estrela no SQL Server** em camadas `raw → stg → dw → mart`, e serve um dashboard **Streamlit** de 5 páginas, bilíngue (PT/EN).

```
Jolpica-F1 / FastF1  →  ETL (Python)  →  SQL Server (star schema)  →  mart views  →  Streamlit
```

`Python` `SQL Server` `Modelagem Dimensional` `ETL` `Streamlit`

### 📊 [Sales Dashboard BF.Lubs](https://github.com/brendongarcia/powerbi-sales-dashboard-bflubs)

Dashboard de vendas com **medidas DAX avançadas** — comparativo anual, YTD, delta e percentual de crescimento usando `SAMEPERIODLASTYEAR`, `TOTALYTD` e `DATEADD`.

`Power BI` `DAX` `Power Query` `Modelagem de Dados`

### 📈 [Sales Overview 2022](https://github.com/brendongarcia/sales-overview-powerbi)

Relatório interativo de performance comercial: receita, custo, margem, evolução mensal e distribuição geográfica.

`Power BI` `ETL` `Data Visualization`

### 🏦 [NodeBank CLI](https://github.com/brendongarcia/NodeBank-CLI)

Sistema bancário em linha de comando com Node.js: criação de contas, consulta de saldo, depósito e saque.

`Node.js` `JavaScript` `CLI`
